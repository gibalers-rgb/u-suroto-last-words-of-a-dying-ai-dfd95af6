A program that writes the funniest one-line farewell from an AI being
switched off — in the machine's own voice — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

## Entry

> I die as I lived: 97% confident, 100% wrong.

Deterministic, standard library only, no network, no secrets.
